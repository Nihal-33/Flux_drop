1. Executive Summary & Product Vision

FluxDrop is a unified, high-performance web platform designed to eliminate the friction of transferring files, snippets, and data across heterogeneous operating systems (Windows, macOS, Linux, Android, iOS). While proprietary utilities such as Apple AirDrop and Google Quick Share restrict high-speed local transfer to their respective hardware walled-gardens, FluxDrop operates universally via modern web standards, WebRTC P2P DataChannels, and resilient Supabase cloud synchronization.

Beyond raw file transmission, FluxDrop introduces an integrated multi-purpose digital workspace comprising a Zero-Trust Numeric PIN Vault with security question recovery, a collaborative Code Studio for real-time snippet sharing, and a lightweight Udhar / Khata Bookkeeping Module tailored for freelancers and local businesses.

2. Problem Statement & Opportunity

  • Cross-Ecosystem Incompatibility: Users who possess both an iPhone and a Windows PC or an Android tablet and a MacBook cannot utilize native peer-to-peer protocols without cumbersome third-party drivers or cloud uploads.
  • Double Bandwidth Inefficiency: Traditional cloud lockers (Google Drive, OneDrive) require complete remote uploads before recipient download can start, exhausting cellular data caps and introducing latency for large media files.
  • Ephemeral Security Risks: Ad-hoc browser transfer utilities often fail to authenticate users or protect workspace storage, leaving files exposed to unauthorized devices on shared Wi-Fi networks.
  • Context Switching for Digital Workspaces: Users routinely shuffle between chat applications (to copy code snippets or links), transfer utilities, and manual spreadsheets to record financial transactions.

4. Core Functional Requirements & Feature Breakdown

4.1 User Authentication & Two-Tier Security Lock

  • Supabase Cloud Auth: Users register with username, email, and password. In cloud deployments (Vercel), requests connect directly to Supabase Auth GoTrue over TLS.
  • Security Question Configuration: During signup, users select a security question (e.g., "What city or place were you born in?", "What was the name of your first school?") and enter a secret answer. The answer is hashed with SHA-256 on the client before storage to ensure zero-knowledge privacy.
  • Numeric Master PIN: A mandatory 4-to-6 digit PIN protects the main workspace. PIN verification issues an ephemeral x-pin-token stored in session storage.
  • Self-Service PIN Recovery: If a user forgets their PIN, answering their configured security question validates the hash and unlocks the account without administrative intervention.

4.2 Device Fingerprinting & Discovery Engine

  • Automatic Device Identification: Captures client OS, browser, device type (Desktop, Laptop, Mobile, Tablet), and screen characteristics, generating a persistent unique Device ID.
  • Radar & Nearby Device Discovery: Displays available peers on the same local network or authenticated user perimeter.
  • Pairing Verification: Supports instant 6-digit numeric pairing codes and QR-code scans with explicit user authorization prompts on the receiving device.

4.3 Hybrid Transfer Mechanism (WebRTC + Cloud Fallback)

  • Primary P2P Channel: Utilizes WebRTC SCTP DataChannels with chunked binary buffers (64KB chunks) for line-rate local throughput.
  • Automatic Cloud Buffer: If WebRTC NAT traversal (ICE handshake) fails or the recipient device is offline, transfers automatically buffer into an S3-compliant Supabase Storage bucket (fluxdrop-files).
  • Integrity Checksums: Computes client-side SHA-256 checksums to verify payload integrity post-transfer.

4.4 Integrated Code & Text Studio

  • Multi-Language Highlighting: Live code editor supporting TypeScript, JavaScript, Python, HTML/CSS, JSON, and Bash.
  • Instant Cross-Device Sync: Code snippets saved to the studio are immediately accessible on all paired devices.
  • Export & Run: Provides one-click copy, download as source file, and formatted markdown preview.

4.5 Udhar / Khata Bookkeeping Module

  • Ledger Management: Record transactions under two primary categories: "Gave" (Maine Diye) and "Got" (Maine Liye).
  • Customer Directory: Add and categorize customers with phone numbers, profile tags, and running balance summaries.
  • Settlement Workflow: Mark outstanding credit as settled with timestamped audit trails.

6. Non-Functional Requirements (NFRs)

  • Performance & Latency: P2P transfer handshake must establish in < 300ms. Local network transfers must utilize up to 90% of available Wi-Fi link bandwidth without CPU throttling.
  • Security & Privacy: Zero storage of plain-text passwords or security answers. All cloud communications enforced via TLS 1.3. Supabase tables protected by Row-Level Security (RLS).
  • Availability & Fault Tolerance: 99.9% uptime powered by Vercel Global Edge Network and Supabase multi-zone cloud infrastructure.
  • Responsive Cross-Device Layout: Viewports from 320px (mobile) to 3840px (4K monitors) render seamlessly without horizontal scrolling or distorted modals.
