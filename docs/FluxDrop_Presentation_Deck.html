The Problem: Cross-Platform File Transfer is Broken

Modern professionals operate across multi-OS setups, facing severe friction in simple data transfers.

Ecosystem Lock-in

Walled Gardens

Apple AirDrop works brilliantly—until you need to send a file to Windows, Linux, or Android. Users resort to sending files to themselves on WhatsApp or Slack.

  • No native Mac-to-PC or PC-to-iPhone protocol
  • Compression artifacts on image/video transfers
  • Manual clean-up of temporary messaging chats
Cloud Bloat

Slow Cloud Intermediate

Google Drive and Dropbox require full uploads before the recipient can even start downloading, choking on slow networks and low quotas.

  • Double bandwidth usage (Upload + Download)
  • Quota exhaustion on 15GB free tier limits
  • Cumbersome link generation and access permissions
Security Vulnerabilities

Zero Zero-Trust Control

Ephemeral WebRTC tools lack access control, account persistence, and device verification, leaving internal network devices exposed.

  • No persistent device trust or pairing memories
  • Lack of second-factor security for sensitive vaults
  • No integrated ledger or snippet sharing workspace

Core Innovation
03 / 10

The Solution: FluxDrop Hybrid Transfer Engine

Combining instant P2P local transfer with cloud-grade resilience, persistent vaults, and security.

Ultra-Fast P2P

Direct WebRTC DataChannel

When devices are on the same local network or reachable via STUN/TURN, transfers stream directly peer-to-peer at line-rate gigabit speeds with zero intermediary storage.

  • Zero server bandwidth consumption
  • Zero file size caps for local transfers
  • End-to-end encrypted payload streaming
Cloud Fallback

Supabase S3 & Postgres Sync

When recipient devices are offline or across restricted firewalls, FluxDrop seamlessly buffers the payload into secure Supabase Storage with expiring signed URLs.

  • Asynchronous delivery when receiver comes online
  • Automated SHA-256 integrity verification
  • Granular Row-Level Security (RLS) policies
Unified Workspace

More Than Just File Transfer

FluxDrop integrates an interactive Code Studio for snippet sharing and an Udhar/Khata ledger module for tracking business credit and daily transactions.

  • Live code editor with language syntax highlighting
  • Digital Khata ledger with balance calculations
  • Real-time connected device heartbeat monitoring

Security Model
05 / 10

Defense-in-Depth Security & Identity System

Zero-trust architecture ensuring unauthorized devices cannot intercept transmissions or access files.

Authentication & PIN Architecture

Two-Tier Authentication Pipeline

Account creation registers users into Supabase Auth with an associated security question. Access to sensitive storage requires passing the Security PIN check.

1. Registration: Email + Password → Supabase Auth
2. Security Question: "Birth City" → SHA-256 Hash Stored in DB
3. PIN Lock: 4-6 Digit Master PIN hashes checked in session
4. PIN Forgot: Question Answer verified → Generates Unlock Token
Database & Storage Isolation

PostgreSQL Row-Level Security (RLS)

Every database record in `users`, `pins`, `devices`, `files`, and `udhar_*` is isolated. Files in Supabase Storage buckets use signed download URLs with strict TTLs.

• storage.objects: Strict bucket isolation ('fluxdrop-files')
• Device Tokens: Ephemeral cryptographic tokens per session
• Passwords: Managed securely by Supabase GoTrue engine
• Mixed Content Free: 100% TLS/HTTPS communication

Real-time signaling hub for device discovery and WebRTC handshake.

Enterprise-grade serverless persistence and cloud object storage.

  • Database: PostgreSQL with JSONB and RLS
